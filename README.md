# Contract IQ

### AI-Assisted Contract Review for macOS

Contract IQ is a macOS application built with SwiftUI that explores how AI can support structured contract review and negotiation workflows.

## Key Features

- AI-assisted clause drafting and revision
- Negotiation playbooks with target and fallback positions
- Original-versus-proposed clause comparison
- Revision history and human review workflows
- Structured Markdown review-package export

## Technology Stack

Swift · SwiftUI · AppKit · Firebase Authentication · Cloud Firestore · Xcode

## Project Overview

Contract IQ combines contract workflow management with AI-assisted drafting and human review. The project focuses on making proposed contractual changes easier to inspect and review.

AI-generated contractual language should be reviewed by a qualified legal professional before use in an actual agreement.
